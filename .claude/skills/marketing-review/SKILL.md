# マーケティングレビュー

このスキルが起動されたら、Agent ツールで `marketer` サブエージェントを起動してレビューを実行する。

## 手順

1. レビュー対象を特定する
   - 引数やユーザーの依頼で対象(特定ページ、直近の変更、サイト全体)が指定されていればそれに従う
   - 指定がなければサイト全体を対象とする
2. Agent ツールで `subagent_type: "marketer"` を指定して起動する
   - プロンプトには以下を含める:
     - レビュー対象(ファイルパスやページの範囲)
     - プロジェクトの概要(ローイング記録・検索サイト、Next.js 製、frontend/ 配下)
     - 「インパクト×実装コストで優先順位付けして報告」という指示
3. サブエージェントの結果はユーザーには直接表示されないため、報告内容を要約せず**そのまま**ユーザーに提示する
4. 改善の実装はユーザーが指示した場合のみ行う(レビューと実装は分離する)

## 注意

- レビューのみを行い、このスキル内でコードは変更しない
- 直近の変更のレビューを頼まれた場合は `git diff` / `git log` で変更範囲を特定してからサブエージェントに渡す

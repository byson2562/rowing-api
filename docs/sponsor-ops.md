# スポンサー運用手順

スポンサーの申込・入金・掲載を扱うときの手順。**個人情報(氏名・メール)はこのリポジトリに一切置かない。**
台帳は Google スプレッドシート、決済の状態は Stripe が真実。

## 情報の置き場所

| 何を | どこに | 備考 |
|---|---|---|
| 決済・更新・解約の状態 | Stripe | 唯一の真実。台帳の「状態」列はここの写し |
| カード申込の通知 | Stripe からの通知メール | `checkout.session.completed` 相当 |
| 銀行振込・企業相談の申込 | Formspree(受信メール) | /sponsor と /contact のフォーム |
| 横断台帳 | Google スプレッドシート「スポンサー台帳」 | 掲載可否・掲載名・更新期限を一覧する場所 |
| サイトに出す名前 | `frontend/lib/sponsors.ts` | 公開してよい表示名のみ。メール等は書かない |

## 台帳の列

```
申込日 / 経路 / お名前 / メール / 口数 / 年額 / 掲載可否 / 掲載名 / 次回更新日 / Stripe顧客ID / 状態 / 備考
```

- **経路**: `カード` または `振込`
- **掲載可否**: `掲載する` / `掲載しない`(既定は掲載する。申込時にオプトアウトされた場合のみ「掲載しない」)
- **掲載名**: サイトに出す表記。指定がなければお名前と同じ
- **次回更新日**: カードは Stripe の次回請求日、振込は入金日の1年後
- **状態**: `有効` / `解約` / `未入金`

## 申込が入ったときの手順

### カード決済(Stripe)
1. Stripe から通知メールが届く
2. Stripe ダッシュボードの該当の支払いを開き、顧客ID・口数・カスタムフィールド「サイトへのお名前の掲載」の回答を確認
3. 台帳に1行追加(状態=有効)
4. 掲載する場合は下記「掲載の反映」へ
5. お礼のメールを送る

### 銀行振込
1. フォームの通知メールが届く
2. 振込先を返信で案内し、台帳に1行追加(状態=未入金)
3. 入金を確認したら 状態=有効、次回更新日=入金日の1年後 に更新
4. 掲載する場合は下記「掲載の反映」へ
5. お礼のメールを送る

## 掲載の反映

`frontend/lib/sponsors.ts` の `sponsors` 配列に追記してコミット・push する。

```ts
export const sponsors: Sponsor[] = [
  { name: "掲載名" },
  { name: "企業名", url: "https://example.com" } // url は企業・団体協賛のみ
];
```

配列が空のあいだはフッターの協賛枠自体が描画されない。

## 定期作業

- **毎月**: Stripe の「サブスクリプション」一覧と台帳を突き合わせ、解約・決済失敗を台帳と `sponsors.ts` に反映する
- **毎年(振込の方)**: 次回更新日の1か月前に継続確認のメールを送る
- **確定申告前**: Stripe から年間の取引CSVを書き出す

## 解約されたとき

1. 台帳の状態を `解約` にする
2. `sponsors.ts` から名前を削除するのは**支払い済み期間の終了後**(/legal に「期間の終わりまでは掲載を継続」と明記しているため)

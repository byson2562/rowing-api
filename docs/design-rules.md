# レガッタナビ デザインルール

toC向けのフラット基調(白地・ヘアライン・ソリッドカラー)を、公開デザインシステム3つを基準に成文化したもの。
UIを新規作成・変更するときは必ずこのルールに従う(適用は `.claude/skills/design-rules` スキル経由)。

参照基準:
- **shadcn/ui** … コンポーネントの寸法・質感の辞書(白地/1pxヘアライン/radius 8-12/ソリッド)
- **デジタル庁デザインシステム** … 日本語タイポグラフィとアクセシビリティの数値基準
- **Vercel Geist** … 高密度データテーブル・バッジ・空状態の見せ方
- (補助) Uber Base … チャート配色の考え方 / SmartHR … UI文言のトーン

## 1. 基準との対応表(現状トークンとの差分)

| 項目 | 基準(出典) | 現状 | 判定 |
|---|---|---|---|
| 背景 | 純白、ページ全面の色地は使わない(shadcn/Geist) | `--bg #ffffff` | ✅ 準拠 |
| カード | 白+1px罫線または極小影、常時の浮遊影なし(shadcn) | ヘアライン+1px接地影(`--shadow*`) | ✅ 準拠 |
| radius | 8〜12px、pillはタグのみ(shadcn) | card 12 / control 10 / pill=タグ系のみ | ✅ 準拠 |
| ボタン | ソリッド1色+ホバーで僅かな変化(shadcn) | primaryソリッド、hoverで1px浮き | ✅ 準拠 |
| グラデーション | 装飾グラデは使わない(shadcn/Geist) | 全廃済(波モチーフのみ残置) | ✅ 準拠 |
| 本文サイズ | 16px、長文行間1.7前後(デジタル庁) | 16px / 記事1.95・UI 1.6-1.7 | ✅ 準拠 |
| 最小文字 | 12px未満は原則使わない(デジタル庁) | 11pxが数箇所(メトリクスラベル等) | ⚠️ 11pxは「英大文字ラベル/タグ内」限定で許容 |
| コントラスト | 文字4.5:1以上(デジタル庁/WCAG AA) | muted `#5d7398`≒4.6:1 ほか主要色は準拠 | ✅ 準拠(新色追加時は必ず検証) |
| 入力欄の高さ | 36-40px(shadcn) | 検索フィルタ44px / LPフォーム40px / 小型34px | ⚠️ 是正候補: 40pxへ統一 |
| フォーカス | `focus-visible` でリング表示(shadcn/Radix) | `focus:` と `focus-visible:` が混在 | ⚠️ 是正候補: focus-visibleへ統一 |
| テーブル | 13-14px・罫線は水平のみ・ヘッダ薄地(Geist) | 13px・水平罫線・#f2f8ffヘッダ | ✅ 準拠 |
| チャート | カテゴリ色は少数に限定+グレー基調グリッド(Uber Base) | 青/金の2色+`#e4eefb`グリッド | ✅ 準拠 |

⚠️の2点(入力44→40統一、focus-visible統一)は今後のUI変更時に順次是正する。

## 2. カラートークン(`frontend/app/globals.css` の `:root` が唯一の出典)

| 役割 | トークン | 値 | 用途 |
|---|---|---|---|
| 背景 | `--bg` | `#ffffff` | ページ地。**色付きの全面背景は禁止** |
| 面(弱) | `--surface-soft` | `#f8fbff` | 区別したいパネルの地(ガイド・CTA等) |
| 罫線 | `--border` | `#dbe7fa` | 標準ヘアライン(1px) |
| 罫線(弱) | `--border-soft` | `#e3edfb` | 補助的な区切り・破線 |
| 本文 | `--text` | `#20304d` | 基本文字色 |
| 補足 | `--muted` | `#5d7398` | ラベル・注釈(白地でAA確保済) |
| 主色 | `--primary` | `#1d6ee0` | ボタン・アクティブ状態・下線 |
| 主色(淡) | `--primary-soft` | `#eef5ff` | チップ地・バッジ地・テーブルヘッダ |
| 強調 | `--accent` | `#ff8a3d` | **1画面1箇所まで**(結果ジャンプ・寄付) |
| リンク | `rn-link` | `#3f60a0` | テキストリンク・二次ボタン文字 |
| 見出し紺 | `rn-brand` | `#17345a` | 見出し・カード表題 |

ルール:
- 新しい色を増やさない。必要になったらまずトークンで代替できないか検討し、増やす場合はここに追記+コントラスト検証。
- Tailwindでは `rn-*` トークンユーティリティ(`bg-rn-primary` 等)を優先。トークンにない固有色のarbitrary値は既存箇所の踏襲のみ。

## 3. 形・深度

- **radius**: カード `rounded-rn-card`(12px) / 入力・ボタン `rounded-rn-control`(10px)・`rounded-[10px]` / 大型トグル `rounded-xl`(12px)。
- **pill(999px)はタグ系のみ**: チップ、性別タブ(セグメント)、順位バッジ、ヒーロータグ。ボタン・入力・ページ番号には使わない。
- **影は常時付けない**: カードは `shadow-rn-soft`(ヘアライン+接地1px)または `border border-rn-border`。どちらか一方で二重線にしない。
- **浮くのはホバー時のみ**: `hover:-translate-y-0.5 hover:shadow-[0_8px_18px_rgba(16,42,80,0.1)]` 程度まで。`motion-reduce:` を必ず併記。
- **グラデーション禁止**(背景・ボタン・下線とも)。ブランド装飾は検索ヒーローの波線のみ。

## 4. タイポグラフィ

- フォント: Inter + Noto Sans JP(現行スタック)。
- サイズ階層(これ以外を増やさない):
  - 見出しL `clamp(1.3rem,3vw,1.8rem)` / 見出しM `1.2rem` / カード表題 `1.05rem`
  - 本文 `16px` / UI標準 `14px` / 補足・表 `13px` / ラベル `12px` / タグ内・英大文字ラベルのみ `11px`
- 行間: 長文 `1.7〜1.95` / UI `1.5〜1.6`。named `text-sm` 等は line-height を束ねるため使わず、`text-[13px]` + `leading-[…]` で指定。
- ウェイト(3段+特例): 本文400 / ラベル・タグ500 / 操作(ボタン・リンク)600 / 見出し・数値700(見出し特例750/800)。
- 数値(タイム・順位・件数)は `[font-variant-numeric:tabular-nums]` を付ける。

## 5. スペーシング

4pxグリッド。使用可能なステップ: 4 / 6 / 8 / 10 / 12 / 14 / 16 / 18 / 24 / 32。
- セクション間 `gap-8`(32px) / カード内要素 8〜12px / カードpadding 14〜24px。
- 階層は「箱」ではなく余白と見出しで作る。同じ重さの箱を3つ以上並べない。

## 6. コンポーネント規定(実装の単一ソース)

スタイルは以下のモジュールに集約されている。**JSXに生のarbitrary値を直接書き足す前に、まず該当モジュールへ**:

| 領域 | モジュール |
|---|---|
| ボタン | `frontend/components/ui/button-classes.ts`(Button / ButtonLink) |
| 検索UI | `frontend/components/search/search-classes.ts`(`sx`) |
| 静的LP | `frontend/components/lp/lp-classes.ts` |
| 記事 | `frontend/components/article/article-classes.ts` |
| ホーム | `frontend/app/page.tsx` 冒頭の定数 |

規定値:
- **ボタン**: 高さ約40px(`py-2.5`)、radius 10px、primary=ソリッド`--primary`白文字 / secondary=白地+`rn-link`文字+ヘアライン。disabledは `opacity-55〜65 + cursor-not-allowed`。
- **入力・select**: 1px `border-rn-border`、白地、radius 10px、フォーカスで `outline-2 outline-[rgba(29,110,224,0.25)] + border-rn-primary`(新規は `focus-visible:` を使う)。
- **テーブル**: 水平罫線のみ、ヘッダ `#f2f8ff` 地+600、数値列は右寄せ+tabular-nums、行ホバー `#f3f8ff`。モバイル(≤640/768)は data-label 付きカード積みに切替。
- **チップ/タグ**: pill、`--primary-soft` 地、12px/500。
- **順位バッジ**: pill 30px、非メダル=`--primary-soft`、金`#ffd76e`/銀`#e5e7eb`/銅`#f5d0a9`(色と太さは基底と排他で合成する)。
- **空状態**: 破線ヘアライン+`--surface-soft` 地+次の行動ボタン(Geist流: 必ず1アクション添える)。
- **チャート**: 青`#5b8ff9`系/金系の2色まで。グリッド`#e4eefb`、ラベル11-12px。

## 7. アクセシビリティ

- 文字コントラストAA(4.5:1)。新色は必ず検証。
- インタラクティブ要素にフォーカスリング必須。`aria-expanded` / `aria-controls` / `role` は既存実装(詳細条件・コンボボックス)の水準を保つ。
- アニメーションには `motion-reduce:` 対応を必ず併記。
- タップ領域はモバイルで40px以上(`max-[768px]:min-h-10` 等)。

## 8. 禁止事項(ダサさの再発防止)

1. 全面色付き背景・背景グラデーション
2. 常時の大きなドロップシャドウ(浮遊カード)
3. ボタン・入力へのpill(999px)
4. 装飾グラデーション(ボタン・見出し下線含む)
5. 新規の枠線色・文字色の場当たり追加
6. 「箱の中に箱」のネスト、同重量の箱の羅列
7. 12px未満の本文(タグ内・英大文字ラベルを除く)
